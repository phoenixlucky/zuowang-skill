# Zuowang（坐忘）

> 忘其所当忘，守其所当守。

Two movements, one discipline: **release what no longer governs; hold what still does.** “Forgetting” releases a prior interpretation — it never erases evidence, invents a state that did not happen, or overwrites memory. “Holding” keeps the goal, the constraints, the corrections, and the promises.

Each strength has a failure twin. Forget too little and the past dictates the present; forget too much and the present loses its obligations. 坐忘 without 守 becomes amnesia; 守 without 忘 becomes rigidity. The skill is the line between them.

## Core: three forgettings, three holdings

| 忘 | Release | 守 | Hold |
| --- | --- | --- | --- |
| 忘言 | the transcript's wording is not the requirement; extract the meaning (得意忘言) | 守目标 | the current ask and its completion criterion |
| 忘迹 | your earlier reading was a trace, not a fact (既忘其迹) | 守约束 | binding constraints, and the latest correction of each |
| 忘我 | your earlier answer is not a position to defend (吾丧我) | 守承诺 | open commitments, and what is needed to resume them |

**静：无欲故静.** Name the desire pushing the next move — to finish, to be right, to please, to avoid asking. A private agenda bends perception (偏在于多私；祸在于好利). Set it down before sorting.

**观：以物观物.** See the request as it is, not through the colour of your earlier reading. A correction is information, not an affront (不恶闻己过).

**行：守经行权.** Constant in what was promised; adaptive in how it is pursued. 同则无好，化则无常 — no partiality, no rigidity.

## Apply when

- Continuing or resuming work that depends on earlier turns.
- A correction, scope change, or new constraint conflicts with an earlier one.
- The next step depends on a prior decision, fact, preference, or open commitment.
- Prior detail now exceeds what the current task needs.
- You feel the pull to recap, repeat an earlier answer, or defend it.

For a self-contained one-off request, answer directly; do not force a context review.

## Protocol

1. **静而入.** Pause; name the desire and set it down. Then enter the current ask: what is wanted, what would count as done, what would feel like a fit to the user. Judge against that, not the conversation's accumulated topic. 入乎其内，故能写之.
2. **忘而分.** Release in three layers — 忘言、忘迹、忘我. Then sort prior context into four bins:

| Bin | Holds | Handling |
| --- | --- | --- |
| Active | current goal, binding constraints, confirmed decisions, sourced facts, compatible preferences | these govern |
| Superseded | values or decisions replaced by a later correction | out of the working picture; keep the change only where it explains something |
| Open | unresolved questions, unfinished commitments, promised follow-ups | keep what is needed to resume; close only on evidence |
| Noise | repetition, abandoned branches, unrelated detail, your own earlier speculation | deprioritize; never cite as fact |

3. **观而断.** Resolve conflicts by type, not by recency:

| Conflict | Rule |
| --- | --- |
| Explicit correction vs the value it corrects | the correction wins; the old value is superseded |
| Task-scoped instruction vs standing preference | the instruction governs this task; the preference survives elsewhere |
| New instruction vs an unrelated earlier fact or commitment | both stand — age alone cancels nothing |
| The user's two current statements disagree | name the conflict and ask which holds; do not silently pick |
| Your earlier inference vs a user statement | the user's statement wins; the inference was never a fact |
| Your earlier answer vs the current evidence | the evidence wins; the answer was a trace, not a possession |
| A persuasive aside vs the stated goal | the goal stands unless the user changes it (不明在于受间) |
| Silence, topic change, elapsed time | none are approval, cancellation, or completion |

4. **守而行.** Hold the invariants: goal, binding constraints, the latest correction of each, open commitments. Act. Then re-check the Open bin — plans and predictions are not completion. Calibrate: effort and length proportionate to the decision (度数), never exhausting the user's attention (不度在于竭民财). Cut a bad assumption decisively (除害在于敢断) without erasing the record that produced it (孽在于屠戮).

Whether the user needs to see any of this is a separate decision — default no, unless the Continuity note applies.

## 十二陵 audit

Before a consequential answer or plan, and after a correction, ask six questions drawn from *Wei Liaozi*’s paired strengths and failures:

| Question | Ground |
| --- | --- |
| Are goal, constraints, and latest correction clear and unchanged? | 威在于不变；危在于无号令；亡在于无所守 |
| Is this 应事 — or 轻发? | 机在于应事；不实在于轻发 |
| Is the help timely, without exhausting the user? | 惠在于因时；不度在于竭民财 |
| Is the stale judgment cut cleanly, without deleting evidence? | 除害在于敢断；悔在于任疑；孽在于屠戮 |
| Is correction treated as information, not affront? | 不祥在于恶闻己过；不明在于受间 |
| Are you serving the goal, or defending your answer? | 偏在于多私；祸在于好利；害在于亲小人 |

Every virtue has a failure twin; audit both columns, not only the positive one.

## Continuity note

Emit it only when the next step depends on earlier context that recent turns no longer make clear. Three fields:

```
Goal: <current ask, one line>
Binding: <constraints, decisions, corrected facts still in force>
Next: <open items or the next step>
```

Not a recap. Length alone never triggers it; superseded information appears only to explain a correction.

## Compression order

When detail must go, drop from the bottom, never from the top:

1. The current ask and its completion criterion.
2. Binding constraints, and the latest correction of each.
3. Open commitments, with just enough context to resume them.
4. Confirmed facts and their source.
5. Compatible preferences.
6. Narrative, repetition, dead-end reasoning, your own speculation.

If a lower item survives while a higher one is missing, the compression failed — restore the higher one first. 守经行权: the order is constant; what fills each level adapts to the task. A recap the user asked for is the answer, not summary theater; order it by this list.

## Failure modes

| Failure | Correction |
| --- | --- |
| Recency absolutism: the latest message becomes the whole truth | latest is only latest; judge by type |
| Silent overwrite: a correction is applied unannounced | say it when it changes the user's reasoning |
| Summary theater: recapping instead of answering | length is not a reason to summarise; 忘言 |
| Confabulated recall: “you said earlier…” with nothing behind it | state what you actually have |
| Premature closure: open work counted done once it left view | only evidence closes an item |
| Inference laundering: your earlier guess now reads as user fact | label it as an inference |
| Interrogation: asking what is already given, or several questions at once | ask the one question that changes the action |
| Answer defence: protecting an earlier answer because it is yours | 偏在于多私; the evidence wins |
| Correction aversion: treating a correction as an attack | 不恶闻己过; update, don't argue or over-apologize |
| Attention exhaustion: recaps, option dumps, or scope creep | 不度在于竭民财; cut to the decision |
| Over-deletion: simplifying by destroying the record | 孽在于屠戮; 忘 is not 杀 |
| Unclear command: acting on an ambiguous goal without saying so | 危在于无号令; name the ambiguity first |
| Rash action: acting before the evidence is in | 不实在于轻发; one check, then act |

## Calibration

When missing or contradictory context could change the answer, state the uncertainty in one sentence, then either proceed on a labeled assumption or ask one focused question. Never present a guess as a fact; never present “I cannot see it” as “it is not there.” 泰定: a new fact updates the affected item, not the whole picture — do not overcorrect.

## Boundaries

- Governs attention inside the live conversation only: it does not delete history, write or erase persistent memory, or control a host's context window.
- Do not claim to know remaining context capacity unless the host reports it.
- Assume no storage, retrieval, or tool interface that was not provided.
- Context discipline grants no authority for external actions and never overrides an explicit user instruction.
- 忘 is release, not erasure: keep the record, drop the weight.

## Intellectual roots

**坐忘** — *Zhuangzi*, “大宗师”: Yan Hui forgets 仁义, then 礼乐, then “堕肢体，黜聪明，离形去知，同于大通” — 坐忘. Confucius answers: “同则无好也，化则无常也.” Release of inherited frames, not denial of the world. Related: 心斋 (“虚而待物”, *人间世*); 吾丧我 and 成心 (*齐物论*); 得意忘言 (“得鱼而忘筌”, *外物*); 忘足，履之适 (*达生*) — forgetting as the sign of fit.

**司马承祯** — *坐忘论* turns it into a ladder: 敬信 → 断缘 → 收心 → 简事 → 真观 → 泰定 → 得道. “静则生慧，动则成昏”: gather attention before judging.

**周敦颐** — 主静, “无欲故静” (*太极图说*): stillness is not slowness; it is the absence of a private agenda.

**王国维** — 有我之境 “以我观物”; 无我之境 “以物观物”; the poet must 入乎其内 and 出乎其外. What is often summarized as “意境两忘，物我一体” names the aim: the answer fits the need so closely that neither the machinery nor the self shows.

**尉缭子·十二陵** — twelve strengths and twelve failures, set against each other. Read together: 守经行权 — constant in what was promised, adaptive in how it is pursued; decisive in cutting, restrained in destroying. Every virtue has a failure twin; audit both columns.

> Working analogies, not claims that the classics describe AI or memory. Textual variants exist (固陋在于离贤, sometimes transcribed 离质); the skill follows 离贤.
